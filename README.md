# attendance-helper-ios

Scriptable 今日打卡小组件 + 快捷指令提醒（`scriptable/AttendanceHelper.js`）。

## 模式

| 参数 | 说明 |
|------|------|
| `widget` | 桌面小组件 / 预览 |
| `leave` | 离开公司：按工时判定考勤，识别是否漏打下班卡 |
| `schedule9` | 工作日预约快满 9 小时提醒 |
| `near9` | 定时检查快满 / 已满，已满时同步判定下班卡 |
| `debug` | 查看解析结果与考勤判定 |

## 考勤判定

1. 未打上班卡 → 未打卡  
2. 工时未满 9 小时 → 还差 X 分钟  
3. 工时已满且无离场记录 → 漏打下班卡  
4. 工时已满且有离场记录 → 考勤正常  

有离场记录即视为已打下班卡，不因离场时间久远判定漏卡。
