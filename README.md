# attendance-helper-ios

Scriptable 今日打卡小组件 + 快捷指令提醒（`scriptable/AttendanceHelper.js`）。

## 模式

| 参数 | 说明 |
|------|------|
| `widget` | 桌面小组件 / 预览 |
| `refresh` | 快捷指令点击刷新：拉最新数据、不弹预览 |
| `leave` | 离开公司：按打卡工时判定考勤，识别是否漏打下班卡 |
| `schedule9` | 工作日预约快满 9 小时提醒 |
| `near9` | 定时检查快满 / 已满，已满时同步判定下班卡 |
| `debug` | 查看解析结果与考勤判定 |

## 点击小组件刷新

点桌面会打开快捷指令 `更新打卡小组件`。若「点一下有时不更新」，通常是快捷指令配法或接口缓存，而不是脚本没跑。

推荐把该快捷指令做成 **只含一个动作**：

1. Scriptable → **刷新所有小组件**
2. 快捷指令开关里关闭「显示运行时」/「在运行时显示」

不要用「运行脚本」再弹一次小组件预览：那样会离开桌面，桌面上的组件快照往往不会立刻变。

脚本侧已做这些配合：

- 打卡接口禁用 HTTP 缓存（避免刚打下班卡仍显示「暂无」）
- 点击 URL 使用 `x-callback-url` 并带时间戳（减轻 iOS 吞掉同 URL 首次点击）
- 从快捷指令进入时不再 `presentMedium`

## 考勤判定

工时以接口上下班卡计算（下班卡时间 − 上班卡时间；若接口直接返回工时字段则优先使用）。

1. 未打上班卡 → 未打卡  
2. 无下班卡 → 漏打下班卡  
3. 有下班卡但工时未满 9 小时 → 还差 X 分钟  
4. 有下班卡且工时已满 → 考勤正常  

## 还差多少分钟

- **默认**：按当前时间相对可下班时间倒计时  
- **已过可下班时间且已打下班卡**：改按打卡工时（下班卡 − 上班卡）差额计算  

## 进度条

已打下班卡，且下班卡时间已达到/超过可下班时间时，小组件不展示进度条。
