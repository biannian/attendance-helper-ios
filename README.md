# attendance-helper-ios

Scriptable 今日打卡小组件 + 快捷指令提醒（`scriptable/AttendanceHelper.js`）。

## 更新到手机

仓库是私有的，Scriptable 不能直接打开 GitHub 页面。不用再复制整份 `AttendanceHelper.js`。

1. 在 GitHub 建一个只读 Token：只授权这个仓库，权限勾选 Contents 的 Read。
2. 把 `scriptable/InstallAttendanceHelper.js` 新建到 Scriptable 里，运行一次，粘贴 Token。
3. 安装器会把最新脚本写成 `AttendanceHelper`。小组件选这个脚本。
4. 以后要更新：再运行安装器，或在打卡脚本菜单里点「更新脚本」，参数也可以填 `update`。

钥匙串里的打卡 Token 和 GitHub Token 不会被覆盖清掉。脚本文件会按仓库里的版本整份替换。

## 模式

| 参数 | 说明 |
|------|------|
| `widget` | 手动预览。桌面和锁屏刷新会拉新数据，失败时用今天的快照 |
| `refresh` | 快捷指令点击刷新：拉最新数据、写入快照，不弹预览 |
| `leave` | 离开公司：按打卡工时判定考勤，识别是否漏打下班卡 |
| `schedule9` | 中国工作日预约快满 9 小时提醒 |
| `near9` | 定时检查快满 / 已满，已满时同步判定下班卡 |
| `debug` | 查看解析结果与考勤判定 |
| `update` | 从 GitHub 下载最新脚本 |

## 点击小组件刷新

点桌面会打开快捷指令 `更新打卡小组件`。推荐快捷指令只含一个动作：

1. Scriptable → 刷新所有小组件
2. 关闭「显示运行时」

这样会在桌面上重跑组件并拉取最新打卡。若改成「运行脚本」，参数填 `refresh`，脚本会拉数据并回写快照，不弹预览。

脚本侧会给打卡请求加时间戳，点击地址使用 `x-callback-url` 并带时间戳。

## 锁屏和休息日

锁屏支持矩形、圆形和日期上方一行。还没打下班卡、也还没到可下班时间时，剩余时长用系统倒计时。每次拉到的打卡会写入今天的快照；锁屏或网络失败时用这份快照。

休息日和法定节假日不显示考勤内容。调休补班仍显示。节假日接口失败时按周一到周五判断。

## 考勤判定

工时以接口上下班卡计算（下班卡时间 − 上班卡时间；若接口直接返回工时字段则优先使用）。

1. 未打上班卡 → 未打卡  
2. 无下班卡 → 漏打下班卡  
3. 有下班卡但工时未满 9 小时 → 还差 X小时Y分钟  
4. 有下班卡且工时已满 → 考勤正常  

## 通知

考勤通知只有两行：标题是状态，副标题分成上班卡和下班卡。已经打下班卡时写下班时间；还没打时下班卡写「未打」，并附上可下班时间。还差的时长按小时和分钟写，例如「还差 1小时20分钟」。通知图标是 Scriptable 应用图标，接口不能更换。

## 还差时长

差额按小时和分钟显示，例如还差 1小时20分钟。不足 1 小时仍写分钟，整小时不补 0 分钟。

- **还没打下班卡**：按当前时间相对可下班时间倒计时，工时继续累计  
- **已打下班卡**：工时停在下班卡减上班卡，不再按当前时间累计。未满 9 小时的差额也按这两张卡计算  

## 进度条

已打下班卡，且下班卡时间已达到或超过可下班时间时，小组件不展示进度条。
