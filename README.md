# attendance-helper-ios

Scriptable 今日打卡小组件 + 快捷指令提醒（`scriptable/AttendanceHelper.js`）。

## 更新到手机

仓库是私有的，Scriptable 不能直接打开 GitHub 页面。不用再复制整份 `AttendanceHelper.js`。

1. 在 GitHub 建一个只读 Token：只授权这个仓库，权限勾选 Contents 的 Read。
2. 把 `scriptable/InstallAttendanceHelper.js` 新建到 Scriptable 里，运行一次，粘贴 Token。
3. 安装器会把最新脚本写成 `AttendanceHelper`。小组件选这个脚本。
4. 以后要更新：再运行安装器，或在打卡脚本菜单里点「更新脚本」，参数也可以填 `update`。

钥匙串里的打卡 Token、GitHub Token、账号、密码和设备 ID 不会被覆盖清掉。脚本文件会按仓库里的版本整份替换。

## 账号、密码、设备 ID

这三项不要写进脚本。用快捷指令传一次，脚本会记在钥匙串里。

1. 三个「要求输入」：账号、密码、设备 ID。
2. 「词典」动作，键名用 `username`、`password`、`deviceId`，再加 `mode`，值填 `account`。
3. Scriptable「运行脚本」选择 `AttendanceHelper`，参数传入这个词典。

也可以把参数写成四行文本：第一行 `account`，后面三行依次是账号、密码、设备 ID。

换账号时再跑一次。脚本会清掉旧的登录 Token 和打卡快照，再用新账号登录。

在 Scriptable 里直接运行脚本，菜单里的「设置账号」也会写入同一组钥匙串。

## 模式

| 参数 | 说明 |
|------|------|
| `widget` | 手动预览。桌面和锁屏刷新会拉新数据，失败时用今天的快照 |
| `refresh` | 快捷指令点击刷新：拉最新数据、写入快照，不弹预览 |
| `leave` | 离开公司：按打卡工时判定考勤，识别是否漏打下班卡。参数只填 `leave`，账号用钥匙串里的 |
| `schedule9` | 中国工作日预约快满 9 小时提醒 |
| `near9` | 定时检查快满 / 已满，已满时同步判定下班卡 |
| `debug` | 查看解析结果与考勤判定 |
| `update` | 从 GitHub 下载最新脚本 |
| `account` | 快捷指令写入账号、密码、设备 ID |

## 点击小组件刷新

点桌面会打开快捷指令 `更新打卡小组件`。推荐快捷指令只含一个动作：

1. Scriptable → 刷新所有小组件
2. 关闭「显示运行时」

这样会在桌面上重跑组件并拉取最新打卡。若改成「运行脚本」，参数填 `refresh`，脚本会拉数据并回写快照，不弹预览。

工作日 8:00 到 11:00，还没有上班卡时大约每 10 分钟再拉一次。拉到上班时间后停止，倒计时由系统显示，下次再在可下班时间刷新一次。11:00 仍未打卡，或当天已经结束，就等到下一个工作日早上。建议再加一条工作日 8:00 的快捷指令，刷新所有小组件，避免系统推迟第一次刷新。

脚本侧会给打卡请求加时间戳，点击地址使用 `x-callback-url` 并带时间戳。

## 锁屏和休息日

锁屏支持矩形、圆形和日期上方一行。还没打下班卡、也还没到可下班时间时，剩余时长用系统倒计时。每次拉到的打卡会写入今天的快照；锁屏或网络失败时用这份快照。

休息日和法定节假日不显示考勤内容。调休补班仍显示。节假日接口失败时按周一到周五判断。

## 考勤判定

工时以接口上下班卡计算（下班卡时间 − 上班卡时间；若接口直接返回工时字段则优先使用）。

1. 未打上班卡 → 未打卡  
2. 无下班卡 → 漏打下班卡  
3. 有下班卡但工时未满 9 小时 → 还差 X 分钟  
4. 有下班卡且工时已满 → 考勤正常  

## 通知

考勤通知只有两行：标题是状态，副标题是上班时间到下班时间。已经打下班卡时结束时间用下班卡，还没打时结束时间后面标「可下班」。通知图标是 Scriptable 应用图标，接口不能更换。

## 还差多少分钟

- **还没打下班卡**：倒计时跟着当前时间走到应走时间，到点后停止。这段时间不累计工时
- **已打下班卡**：工时固定为下班卡减上班卡。未满 9 小时的差额也按这两张卡计算  

## 进度条

只有打了下班卡、并且工时还没满 9 小时时才显示进度。没打下班卡时不画进度。
